# Speechek

![Значок Speechek](design/approved-icon/icon-128.png)

[English](README.md) | **Русский**

Speechek — бесплатное приложение для голосового ввода в Windows 11 x64, которое превращает речь в текст через ваши собственные API-ключи Gemini. Нажмите горячую клавишу, продиктуйте, нажмите её снова — подтверждённый текст вставляется в поле, активное **на момент вставки**. Один `speechek.exe` работает из системного трея; отдельный Bun/Node-бэкенд и скачивание локальной модели не нужны.

## Что даёт Speechek

1. **Бесплатная диктовка за счёт вашего Gemini Free Tier.** Само приложение бесплатно и не требует подписки. Используемые модели Gemini распознают речь в пределах бесплатного уровня Google AI — с учётом квот, доступности моделей и условий Google.
2. **Несколько ключей добавляют запас — только если они принадлежат проектам с независимыми квотами.** Speechek сам чередует запросы между добавленными ключами, чтобы нагрузка не ложилась на один проект, и переключать ключи вручную перед каждой диктовкой не нужно. Ключи одного проекта делят его лимиты, поэтому их добавление не увеличивает общую квоту. Доступность определяет Google; при ошибке одного ключа Speechek не повторяет запрос на другом автоматически.
3. **Готовый текст с Gemini — без локальных моделей.** Smart-режимы убирают слова-паразиты и форматируют речь по смыслу, чтобы результат было удобнее использовать в сообщениях и документах. Скачивать локальную модель и покупать мощную видеокарту не нужно.
4. **Три режима — не нужно подстраивать все задачи под один способ диктовки.** **Live Smart** распознаёт поток во время речи (вставляется только итог), **Smart** обрабатывает готовую запись и очищает её, **Дословно** сохраняет исходные формулировки без Smart-редактирования.

## Скачивание и установка

Последний установщик — на странице **[github.com/girte/speechek/releases/latest](https://github.com/girte/speechek/releases/latest)**.

- Платформа: **Windows 11 x64**. Интерфейс **установщика** доступен на **английском и русском**; интерфейс самого приложения пока русский.
- Установщик **не подписан**. Windows SmartScreen или Smart App Control могут предупредить вас, а строгая политика — запретить запуск. Платного сертификата подписи пока нет.

## Быстрый старт

1. Скачайте на странице релизов файл NSIS `*-setup.exe` и запустите его. Установка идёт для текущего пользователя — права администратора не нужны.
2. При первой установке установщик предлагает две необязательные галочки, обе сняты: ярлык на рабочем столе и запуск Speechek при входе в Windows. Галочка **Запустить Speechek** на последней странице отмечена по умолчанию.
3. Speechek запускается в системном трее (главного окна нет). Правый щелчок по значку → **Настройка**, затем добавьте один или несколько ключей Gemini в разделе **API-ключи** и нажмите **Применить ключи**. Без сохранённого ключа нажатие горячей клавиши открывает окно настроек вместо записи.
4. Поставьте курсор в нужное поле, нажмите **F2** для начала, произнесите фразу и нажмите **F2** ещё раз. **Escape** отменяет текущую диктовку до передачи текста на вставку. Если приложение не может подтвердить автоматическую вставку, оно показывает «Скопировано — вставьте вручную»: текст уже в буфере обмена, нажмите **Ctrl+V**.
5. Чтобы позже сменить режим, горячую клавишу, микрофон, поведение звука или запуск при входе, откройте то же окно настроек из трея. Общие настройки применяются сразу; локальный порт — после перезапуска. Переключатель запуска при входе пишет ту же запись текущего пользователя, что и установщик, поэтому отдельный шаг в параметрах Windows не нужен.

### Важные оговорки

- Для распознавания нужны **доступ в интернет**, **микрофон**, регион с доступным Google AI API и **Microsoft WebView2 Runtime**. Если WebView2 не установлен, установщик скачает его загрузчик.
- Ваша **речь отправляется Google** для распознавания. На **бесплатном уровне** Google может использовать отправленный контент для улучшения своих продуктов, в том числе с проверкой людьми. Не диктуйте конфиденциальные сведения без оценки условий Google.
- Квоты, доступность моделей и условия Free Tier могут меняться; на платном проекте запросы могут тарифицироваться.

## Приватность кратко

Speechek работает через облако и требует интернет. Речь отправляется Google для распознавания. API-ключи Gemini шифруются средствами Windows DPAPI для текущего пользователя в `secrets.bin` рядом с файлом настроек — они не хранятся рядом с EXE и не лежат в открытом виде. Аудио не сохраняется приложением как файл. Полные пояснения, включая то, что приложение может и чего не может гарантировать, — в [руководстве](docs/user-guide.ru.md).
