◉ SPEECHEK SETTINGS

Settings

General settings apply immediately. API keys use “Apply keys”.

Select the application's interface language. The choice applies immediately and is saved. It does not affect speech recognition or the dictated text.

Settings are available in the Speechek window

This page is open in a regular browser: it cannot read or change app settings, and keys are unavailable here. Open settings by right-clicking the Speechek icon in the Windows notification area → “Settings”.

Recognition mode

Live Smart works while you speak. Smart processes the recording after stopping, while Verbatim preserves the words without Smart editing. A new mode applies to the next recording.
During recording, Speechek mutes the Windows default playback device. It then restores the previous state unless you changed the sound yourself. Recording continues if muting fails.
Speechek will start automatically when the current user signs in to Windows. The installer and this setting use the same registry entry. Enabling it here restores startup if disabled in Windows settings. Signing in may take slightly longer. This setting cannot be changed while its entry cannot be read.

Choose a microphone for the next recording. If it disconnects, Speechek temporarily uses the system microphone and warns you; your choice remains saved.

Starts and stops recording even with settings open. Enter F2 or Ctrl+Shift+Space and press Enter or leave the field. The hotkey cannot be changed during dictation.

App windows use this port. A new value is saved immediately but takes effect after restarting. If the port is busy, the app temporarily uses an available one.

API keys

One key per line. Keys are kept in the protected Windows key store; you can view them only here using “Show keys”.

“Apply keys” saves the list; “Clear list” only changes the draft. “Check keys” checks API access, not quota or recognition quality. Removing all keys requires confirmation.
