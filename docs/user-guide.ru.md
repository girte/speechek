# Руководство пользователя Speechek

[English](user-guide.md) | [Русский](user-guide.ru.md) · Назад к [README](../README.ru.md)

Это руководство описывает установку, ключ Gemini, окно настроек, файлы настроек, приватность, обновление, удаление, автозагрузку и диагностику.

## Требования

- **Windows 11 x64** (установщик запускается и на ARM64 через эмуляцию Windows только как нетиповой сценарий; поддерживаемая платформа — x64).
- **Microsoft WebView2 Runtime.** Если его нет, установщик скачает загрузчик, поэтому первое скачивание требует интернета.
- **Доступ в интернет** для распознавания и регион, где доступен Google AI API.
- **Микрофон**, видимый Windows.

## Установка и первый запуск

Запустите `*-setup.exe`, скачанный со страницы [Releases](https://github.com/girte/speechek/releases). Установщик:

- ставит приложение в профиль пользователя (`%LOCALAPPDATA%\Speechek`), без прав администратора;
- при первой установке предлагает **ярлык на рабочем столе** и **запуск при входе**, обе галочки сняты;
- содержит галочку **Запустить Speechek** на последней странице, отмечена по умолчанию;
- не подписан, поэтому SmartScreen или Smart App Control могут предупредить или заблокировать запуск.

При первом запуске Speechek создаёт `%APPDATA%\Speechek\settings.json` с аннотированным шаблоном и **продолжает работать**: процесс не завершается, отдельный текстовый файл для ключей не создаётся. Окно настроек открывается на разделе **API-ключи / API keys** — впишите хотя бы один ключ Gemini, по одному ключу на строку, и нажмите **Применить ключи / Apply keys**. Перезапуск не нужен. Не храните ключи в `settings.json` и Git. Это путь установленной production-версии; portable dev-сборка хранит свои `settings.json` и `secrets.bin` рядом со своим EXE и не пересекается с установленной.

Главного окна нет: значок живёт в системном трее. Приложению нужны Microsoft WebView2 Runtime, доступ к микрофону и свободный локальный порт (по умолчанию `127.0.0.1:4173`, меняется в «Общих настройках» и применяется после перезапуска). Если сохранённый порт занят при запуске, приложение временно слушает свободный порт и сообщает об этом в окне. Ключи шифруются для текущего пользователя Windows; под другой учётной записью приложение их не прочитает.

## Как получить API-ключ Gemini

1. Войдите в аккаунт Google и откройте [страницу ключей Gemini в AI Studio](https://aistudio.google.com/apikey).
2. Примите условия использования. При первом входе AI Studio сам создаёт проект по умолчанию и ключ. Если этого не произошло или нужен ещё один проект, создайте проект прямо в AI Studio (консоль Google Cloud не нужна) и выпустите в нём ключ кнопкой «Create API key». Там же видно, сколько запросов израсходовал каждый проект. Новые ключи AI Studio выпускаются как authorization (auth) keys.
3. Биллинг не нужен: Free Tier доступен активному проекту без привязанной оплаты и даёт бесплатный ввод и вывод для доступных моделей. Лимиты зависят от модели и считаются **на проект, а не на отдельный ключ**, поэтому ключи одного проекта делят одну квоту; для большего запаса создайте в AI Studio отдельный проект под каждый ключ. Актуальные значения — на [странице лимитов](https://ai.google.dev/gemini-api/docs/rate-limits), доступные модели и цены — на [странице цен](https://ai.google.dev/gemini-api/docs/pricing). Указанные лимиты не гарантированы и могут меняться.
4. Скопируйте ключ (можно несколько), вставьте их по одному на строку в окне настроек, в разделе **API-ключи / API keys**, и нажмите **Применить ключи / Apply keys**. **Проверить ключи / Check keys** подтверждает только доступ (`models.list`), а не квоту, не выбор модели и не качество распознавания.

Бесплатный уровень Gemini API и AI Studio доступны не во всех странах: сверьтесь со [списком доступных регионов](https://ai.google.dev/gemini-api/docs/available-regions). На бесплатном уровне Google может использовать отправленный контент для улучшения своих продуктов — см. [условия](https://ai.google.dev/gemini-api/terms) и раздел «Приватность и ограничения» ниже.

## Быстрый старт

1. Поставьте курсор в нужное текстовое поле.
2. Нажмите **F2** (или настроенную горячую клавишу), произнесите фразу и нажмите её ещё раз.
3. Во время записи плашка занимает 224×48 CSS-пикселей: индикатор, статус и таймер разделены одинаковыми промежутками в 12 пикселей. После остановки остаётся надпись «Обработка / Processing» и вращающийся индикатор; при ошибке плашка расширяется для причины. Когда результат готов, плашка скрывается перед вставкой текста. Она не перехватывает фокус: текст вставляется в поле, активное на момент вставки, и остаётся в буфере обмена.
4. **Escape** во время записи или ожидания расшифровки отменяет текущую диктовку: плашка скрывается, микрофон освобождается, полученный результат не вставляется и буфер обмена не изменяется. Если обработка у Gemini уже началась, отправленный запрос невозможно отозвать задним числом. Вне диктовки Escape остаётся обычной клавишей активного приложения.

Если приложение не может подтвердить автоматическую вставку, оно на несколько секунд покажет «Скопировано — вставьте вручную / Copied — paste manually». Текст уже лежит в буфере: нажмите **Ctrl+V** в нужном поле. Если во время операции вы скопировали что-то другое, Speechek не перезапишет новую копию. После начала передачи текста Windows уже отправленное Ctrl+V нельзя отменить задним числом; нажимайте Escape во время записи или ожидания расшифровки.

Пока не сохранён ни один ключ, диктовка не начинается: нажатие **F2** открывает окно настроек на разделе **API-ключи / API keys** вместо записи.

## Трей и окно настроек

Правый щелчок по значку в трее открывает нативное меню из двух пунктов — **Настройка / Settings** и **Выход / Exit**, именно в этом порядке; сам щелчок окно не открывает. Пункт **Настройка / Settings** показывает единственное окно настроек и сразу отдаёт ему фокус — **в любой момент, в том числе во время диктовки**: начатая запись не отменяется, не останавливается и продолжается как обычно; закрытие окна во время диктовки на сессию так же не влияет. Горячая клавиша запускает и останавливает запись даже при открытых настройках, кроме случая, когда курсор находится в поле смены самой клавиши: там действующее сочетание можно ввести, не начав запись. Место вставки определяется только при готовности текста: если тогда активны настройки, Speechek не вставляет текст в свои поля, а оставляет его в буфере обмена.

- Общие настройки — режим, отключение звука во время записи, микрофон и горячая клавиша — применяются сразу, **перезапуск не нужен**; локальный порт сохраняется сразу, но применяется после перезапуска. API-ключи применяются отдельной кнопкой **Применить ключи / Apply keys**. Параметры записи и список ключей, изменённые во время диктовки, действуют со следующей записи: начатая сессия доигрывает со снимком, снятым на её старте. Язык UI берётся из текущих настроек, а не из снимка записи, и меняется сразу, в том числе во время записи.
- Закрытие окна настроек или лаборатории приложение не завершает. Если в черновике ключей есть реально изменённый или ещё не отправленный список, закрытие окна (и пункт **Выход / Exit**) предлагает **Применить ключи / Apply keys**, **Не применять / Do not apply** или **Вернуться / Return**; **Не применять / Do not apply** уничтожает только черновик ключей и не откатывает уже применённые общие настройки. Просмотр и скрытие сохранённого списка без правок изменением не считаются, и вопрос при закрытии не появляется.
- Пункт трея **Выход / Exit** завершает приложение: освобождаются микрофон, глобальные горячие клавиши и порт. Неприменённый черновик ключей и незавершённое применение при этом не теряются молча.
- Пока идёт запись, горячую клавишу сменить нельзя: поле сочетания заблокировано, а отправка нового значения отклоняется с понятной подсказкой, пока диктовка не завершится или не будет отменена. Остальные параметры записи — режим, отключение звука и операции с ключами — во время записи доступны, но действуют со следующей диктовки и не меняют текущую. Переключатель языка интерфейса остаётся доступным и сразу меняет текст UI.
- Подсказки «?» у настроек открываются при наведении мыши или при фокусе клавиатурой; клик не закрепляет карточку, а уход указателя, уход фокуса, Escape и переключение раздела скрывают её. У самого поля списка ключей лишней подсказки нет: правило **Применить ключи / Apply keys** остаётся в разделе **API-ключи / API keys**. Раскрытый список микрофонов оформляется в цветах приложения, если WebView2 поддерживает настраиваемый `<select>`; в остальных версиях остаётся системный список. Полосы прокрутки настроек и лаборатории остаются видимыми и окрашены в палитру приложения.
- Лаборатория всегда сравнивает все три режима на одной записи; отдельного переключателя сравнения в приложении больше нет, а её кнопка недоступна, пока идёт диктовка. Начатая в лаборатории запись использует тот же нативный захват, что и диктовка, по одному микрофону за раз; закрытие окна лаборатории останавливает её запись, а не оставляет микрофон скрытой странице.

### Язык интерфейса

Переключатель **Язык интерфейса / Language** находится в шапке настроек, над вкладками **Общие настройки / General settings** и **API-ключи / API keys**. Его два пункта всегда называются **English** и **Русский**; третьего автоматического варианта нет.

Успешный выбор сохраняется и сразу обновляет настройки, встроенную лабораторию, плашку, меню трея, заголовки окон, подсказки и сообщения, включая уже показанные статусы и ошибки. Перезапуск не нужен; запись и её таймер продолжаются, черновик API-ключей не теряется, речь и расшифровка не переводятся. Режим распознавания, микрофон и список ключей начатой записи остаются закреплены за этой сессией. Выбор не меняет язык установщика NSIS или удалителя. Лаборатория, открытая отдельно в обычном браузере, обновляет язык при возврате фокуса в её окно, а не через мгновенное событие настроек нативных окон.

Начальный язык определяется в таком порядке:

1. Сохранённый выбор приложения в `language` (`en` или `ru`).
2. Поддерживаемый выбор установщика: английский (`1033`) или русский (`1049`). Отсутствующее, недоступное, повреждённое или неподдерживаемое значение считается отсутствующим.
3. Язык **интерфейса Windows**, не регион или раскладка клавиатуры: русский основной язык выбирает русский, любой другой — английский.

Development игнорирует записи установщика в реестре и при отсутствии сохранённого выбора использует язык интерфейса Windows. Test читает только свою изолированную запись установщика, никогда Production, и хранит отдельный выбор приложения. Смена языка приложения не записывает значение установщика в реестр.

Смена языка не применяет, не очищает и не заменяет черновик ключей. Прежние правила сохранения горячей клавиши и порта не меняются: если ради переключателя вы уходите из одного из этих полей, выполняется обычное сохранение при потере фокуса. Само обновление перевода поля не отправляет и не перезаписывает их неотправленный текст.

### Общие настройки

- **Режим распознавания / Recognition mode**: **Live Smart** — распознавание потока во время речи, итог приходит после остановки; **Smart** — распознавание после записи с удалением слов-заполнителей и форматированием по смыслу; **Дословно / Verbatim** — распознавание после записи без правки. Переключение сразу меняет настройки для следующей записи.
- **Горячая клавиша / Hotkey**: обычное текстовое поле с текущим применённым значением. Введите `F2` или сочетание, например `Ctrl+Shift+Space`, и нажмите Enter либо переведите фокус из поля — законченное значение применится сразу, отдельной кнопки нет; набор по символам только редактирует поле. Одиночные буквы и цифры не принимаются, нужен модификатор (Ctrl, Alt, Shift, Super); одиночные функциональные клавиши F1–F11 и F13–F24 допустимы, `F12` зарезервирована приложением, `Fn` Windows приложениям не сообщает. Пустая строка, `Fn`, `F12` и сочетание из одних модификаторов отклоняются с ошибкой рядом с полем, а прежнее рабочее сочетание продолжает работать. Если сочетание занято другой программой, значение не применяется, а прежняя клавиша остаётся рабочей. По умолчанию горячая клавиша — `F2`. **Escape без модификаторов** отклоняется: Escape зарезервирован для отмены диктовки.
- **Отключать звук во время записи / Mute sound while recording** — при включении Speechek глушит общий звук Windows на устройстве воспроизведения по умолчанию (тот же регулятор, что и клавиша mute) только на время фактической записи с микрофона и возвращает прежнее состояние после остановки или отмены; вне записи звук не трогается. Если вы сами изменили звук во время записи, Speechek сохранит ваше решение. Неудача отключения или возврата не прерывает диктовку: плашка показывает локализованное предупреждение. По умолчанию выключено; изменение действует со следующей диктовки.
- **Запускать Speechek при входе в Windows / Start Speechek when signing in to Windows** — та же запись автозагрузки текущего пользователя, которую может создать установщик: переключатель включён, когда собственная запись Speechek указывает на этот исполняемый файл и Windows её не отключил; выключен, когда записи нет или она отключена; и в смешанном состоянии отключён, пока запись прочитать нельзя. Включение здесь возвращает автозагрузку, отключённую в Windows, поэтому открывать **Параметры → Приложения → Автозагрузка** не нужно; сам вход в систему может занять немного больше времени. Установщик и этот переключатель пишут одно и то же значение реестра.
- **Микрофон / Microphone** — раскрывающийся список устройств записи: пункт **Системное устройство по умолчанию / System default device** и подключённые устройства с их идентификаторами; список обновляется при открытии и активации окна. Выбор сохраняется сразу и действует со следующей записи — и для обычной диктовки, и для встроенной лаборатории; начатая запись доигрывает на прежнем устройстве. Если выбранное устройство отключено, запись идёт с системного микрофона, а плашка и окно предупреждают об этом; сохранённый выбор не заменяется сам — устройство нужно выбрать заново, когда оно снова появится. Лаборатория, открытая в обычном браузере без окна Speechek, использует микрофон браузера. Это выбор устройства **ввода**; он не связан с отключением звука во время записи, которое относится к устройству воспроизведения.
- **Локальный порт / Local port** — порт встроенного сервера, по умолчанию `4173`. Набор по цифрам только редактирует поле; Enter или уход из поля сохраняет целое число из диапазона 1–65535, и оно применяется после перезапуска приложения. Если сохранённый порт занят при запуске, приложение временно слушает свободный порт и сообщает об этом в окне настроек, не перезаписывая сохранённое значение.

### API-ключи

- Значения скрыты: сводка показывает только число сохранённых ключей. **Показать ключи / Show keys** — единственное действие, которое выводит список на экран; переключение раздела, применение ключей или закрытие окна снова его скрывают. Само открытие, просмотр и скрытие списка черновик не меняют: вопрос при закрытии возникает, только если нормализованный список реально отличается от сохранённого или введённый текст ещё не дошёл до приложения.
- Единое поле открывается явным **Показать ключи / Show keys** и пригодно для редактирования. **Очистить список / Clear list** — подтверждённое действие над черновиком: пустое поле станет очисткой только после **Применить ключи / Apply keys**; без сохранённого ключа диктовка отключается.
- **Применить ключи / Apply keys** — единственное действие, которое записывает введённый (или пустой) список в DPAPI-хранилище. Общие настройки, включая язык интерфейса, и горячая клавиша применяются независимо и никогда не читают и не заменяют черновик ключей. Если контейнер недоступен, кнопка **Показать ключи / Show keys** называется **Ввести ключи / Enter keys** и открывает пустой редактор, не раскрывая неизвестные сохранённые значения; замена требует отдельного подтверждения.
- **Проверить ключи / Check keys** проверяет доступ к API Gemini (запрос `models.list`) для текущего черновика, по одному ключу последовательно. Успех подтверждает только доступ, а не выбор модели, качество распознавания или квоту. Проверка ничего не сохраняет, не расходует очередь ключей и не нужна для применения.
- Один ключ на строку; пустые строки и повторы отбрасываются, пробел внутри ключа — ошибка строки с её номером.

## Файл настроек

`%APPDATA%\Speechek\settings.json` — обычный JSON, который можно открыть любым редактором. При первом запуске в него записывается аннотированный шаблон из `config/settings.example.json` (он вшит в EXE), а `language` получает вычисленный начальный язык вместо простого копирования шаблонного `en`. Допускаются только комментарии `//` **отдельной строкой**; встроенные комментарии и лишние запятые не допускаются. Поля `hotkey` и `mode` обязательны и должны встречаться ровно один раз: отсутствующее или продублированное поле делает файл невалидным, а не подставляет значение по умолчанию. `mute_during_recording`, `port` и `input_device` можно не указывать — тогда действуют `false`, `4173` и системное устройство ввода. `language` тоже необязателен: при отсутствии действует порядок выбора начального языка выше. Старый файл читается без перезаписи при запуске; отсутствующие необязательные поля, включая вычисленный `language`, вставляются при следующей успешной записи настроек. Применение без изменений, не выполняющее запись, файл не мигрирует. Запись меняет только управляемые значения и сохраняет посторонние свойства, комментарии, BOM и окончания строк. Явные `null`, число, неподдерживаемая строка или повтор `language` невалидны, а не включают автоматический выбор.

| Поле | Значение |
| --- | --- |
| `hotkey` | Глобальная клавиша записи и остановки, по умолчанию `F2`. Возможны сочетания вроде `Ctrl+Shift+F9`; до клавиши допустимы `Ctrl`, `Alt`, `Shift`, `Super`. Одиночные буквы и цифры, `Fn`, `F12`, сочетания из одних модификаторов и **Escape без модификаторов** запрещены: Escape резервируется на время диктовки для её отмены. |
| `mode` | `live` — Live Smart (потоковое распознавание во время речи); `smart` — обработка готовой записи: удаление слов-заполнителей и форматирование по смыслу; `verbatim` — дословная расшифровка без правки. |
| `mute_during_recording` | `true` — на время фактической записи отключать общий звук Windows на устройстве воспроизведения по умолчанию и возвращать прежнее состояние после остановки или отмены; `false` — не трогать звук. Поле необязательно: отсутствие означает `false`. |
| `port` | Локальный порт встроенного сервера, по умолчанию `4173`; целое число от 1 до 65535. Новое значение применяется при следующем запуске приложения; занятый сохранённый порт не мешает запуску — приложение временно слушает свободный. Поле необязательно: отсутствие означает `4173`. |
| `input_device` | Идентификатор выбранного микрофона в том виде, в каком его выдаёт Windows; `null` или отсутствие поля — системное устройство ввода по умолчанию. Выбор задаётся списком **Микрофон / Microphone** в разделе **Общие настройки / General settings**, сохраняется сразу, действует со следующей записи и не заменяется сам, если устройство недоступно. |
| `language` | Язык интерфейса: `"en"` — английский, `"ru"` — русский. Поле необязательно: при отсутствии используется описанный выше порядок выбора без перезаписи файла при запуске. Выбор через **Язык интерфейса / Language** сразу применяется и сохраняется; он не переводит продиктованный текст и не меняет язык установщика или удалителя. |

Ключей и путей к ним в файле нет: список шифруется отдельно, в `secrets.bin` рядом с `settings.json`.

Путь `%APPDATA%\Speechek` относится к установленной production-версии. У portable dev-сборки профиль отдельный: `settings.json` и `secrets.bin` лежат рядом с её EXE (например, `src-tauri\target\debug`), а не в `%APPDATA%\Speechek`; dev-сборка и установленное приложение не читают и не заменяют файлы друг друга. Шифрование ключей по-прежнему привязано к текущей учётной записи Windows.

Ошибки запуска делятся на два вида. Невалидный `settings.json` — включая порт вне диапазона 1–65535 — останавливает приложение с нативным сообщением: файл при этом не перезаписывается, а другой порт не подставляется. Занятый сохранённый порт запуск больше не останавливает: приложение временно слушает свободный порт и сообщает об этом в окне настроек, а сохранённое значение остаётся прежним. А вот отсутствие ключей, повреждённый `secrets.bin` или занятая на старте горячая клавиша не фатальны: приложение запускается, диктовка остаётся недоступной, и окно настроек открывается на том разделе, где это исправляется — **API-ключи / API keys** при проблеме с ключами, **Общие настройки / General settings** при проблеме только с клавишей; если сломано и то и другое, приоритет у раздела **API-ключи / API keys**.

### Частичное применение

Каждый из двух файлов заменяется атомарно отдельно, но пара `settings.json` + `secrets.bin` не является одной аварийной транзакцией: их запись происходит последовательно, и сбой между ними возможен. Если предыдущее применение не удалось откатить полностью, окно показывает локализованное предупреждение о частичном изменении файлов; приложение продолжает использовать прежние настройки. Предупреждение не снимается закрытием окна или новым открытием, а следующее успешное применение — общих настроек, горячей клавиши или ключей — принудительно перезаписывает и перечитывает все потенциально затронутые файлы; только после этого предупреждение снимается. До успешного применения приложение работает на прежних настройках.

## Как выбирается ключ Gemini

Ключи хранятся в `secrets.bin` рядом с `settings.json` и читаются при запуске. Список нормализуется при применении ключей: пустые строки и одинаковые ключи отбрасываются, остаются только первые вхождения.

Для каждого **принятого** запроса берётся следующий ключ по кругу: первый, второй, третий, снова первый. Один поток Live использует выбранный ключ до закрытия соединения. Один пакетный запрос использует один и тот же ключ для загрузки аудио, распознавания и удаления временного файла. Если применённый список не изменился, очередь продолжается с прежнего места; после изменения списка отсчёт начинается с первого ключа, а уже начатая диктовка доигрывает на прежнем наборе. Ключи одного проекта делят его лимиты: ротация не увеличивает суммарную квоту и не сбрасывает исчерпанные лимиты.

Ошибочный запрос, который отклонён ещё до обращения к Gemini (например, неверный WAV), очередь не сдвигает. Если Gemini отказал уже выбранному ключу, попытка считается потраченной: автоматического перехода на другой ключ и повторного запроса нет. В лаборатории при сравнении трёх режимов запускаются один Live и два пакетных запроса; какой из одновременно отправленных запросов получит очередной ключ, зависит от порядка их поступления.

## Приватность и ограничения

- Ключи шифруются средствами Windows DPAPI **для текущего пользователя** (`CryptProtectData`, без machine scope, без дополнительного пароля и переменных окружения) и лежат в `secrets.bin` рядом с `settings.json`. Файл создаётся с защищённым дескриптором доступа: полный доступ только у SYSTEM и у текущего пользователя. Это защита профиля, а не изоляция по EXE: любой код, запущенный под той же учётной записью, может расшифровать файл теми же средствами Windows.
- Открытого текста ключей на диске нет и резервного пути тоже: чужой, обрезанный или не расшифровываемый контейнер считается ошибкой, а не «пустым списком». `/api/settings` отдаёт только `hotkey`, `mode`, `language` и ревизию runtime `revision` — ни ключей, ни их числа, ни путей. Ключи передаются в окно настроек только по явной кнопке **Показать ключи / Show keys**; сообщения об ошибках приложения вычищают значения ключей. Полностью стереть все копии ключа из процессов WebView, сетевых буферов и системных журналов приложение не обещает.
- Аудио не сохраняется приложением как файл. Пакетная запись временно загружается в Gemini Files API и удаляется после запроса; для Interactions используется `store:false`. Максимальная длительность записи — 10 минут.
- Условия **Google Free-tier** могут допускать использование отправленной речи и ответов для улучшения сервисов, включая проверку людьми. Не диктуйте конфиденциальные сведения без оценки этих условий.
- Пакетный текст вставляется только после подтверждения результата; промежуточный текст Live никогда не вставляется. При невозможности доказать чтение буфера целевым окном приложение оставляет текст для ручной вставки.
- Код механизма вставки адаптирован из Handy по MIT; полный текст — `third_party/Handy.LICENSE`, а в запущенном приложении — `/licenses/Handy.LICENSE`.

## Автозагрузка и панель задач

- **Запуск при входе** предлагается один раз при первой установке (галочка **Запустить Speechek**, отмеченная по умолчанию, — отдельная). Изменить это позже можно переключателем **Запускать Speechek при входе в Windows / Start Speechek when signing in to Windows** в разделе **Общие настройки / General settings**: он пишет ту же запись автозагрузки текущего пользователя, поэтому отдельный шаг в параметрах Windows не нужен, а если автозагрузка отключена в Windows, включение переключателя возвращает её. Если запись прочитать нельзя (имя занято чужой или повреждённой записью), переключатель в смешанном состоянии и отключён, и сообщает об этом, а не показывает состояние, которое Windows не подтвердил. При обновлении на месте установщик не создаёт и не включает запись заново и не переопределяет ручное удаление или изменение в Windows.
- **Закрепление на панели задач** — действие пользователя, а не установщика. Найдите Speechek в меню «Пуск», откройте контекстное меню (**Дополнительно**) и выберите **Закрепить на панели задач**, если это разрешено политикой Windows. Установщик ничего не закрепляет через Shell-скрипты.

## Обновление

У Speechek нет встроенного автообновления и скрытых сетевых самообновлений. Чтобы обновиться, скачайте новый `*-setup.exe` со страницы [Releases](https://github.com/girte/speechek/releases) и запустите его: установщик определит установленную версию и выполнит обновление на месте, сохранив настройки и ключи. Закрыть установщик может только программу, запущенную из папки установки; автономный portable EXE вне папки установки он не завершает — закройте его сами перед запуском установленной версии. Более новый установщик можно запустить и для восстановления, если проверка версии или запись удаления выглядят повреждёнными.

## Удаление

Используйте **Параметры → Приложения → Установленные приложения → Speechek → Удалить** или `uninstall.exe` рядом с установленным исполняемым файлом. Удалитель предупреждает, что перед удалением файлов Speechek будет закрыт. По умолчанию настройки и API-ключи сохраняются; отдельная снятая галочка **Удалить настройки и API-ключи** удаляет реальный профиль `%APPDATA%\Speechek` и данные WebView2 приложения. Удалитель никогда не трогает данные профиля Test (`%APPDATA%\Speechek-Test`) и portable dev-сборки (файлы рядом с её EXE) и не удаляет произвольные каталоги рекурсивно.

## Диагностика

Если значок не появился, проверьте нативное сообщение при запуске: наиболее частые причины — невалидный `settings.json` или порт вне диапазона 1–65535. Если F2 не начинает запись, скорее всего, нет ни одного сохранённого ключа или стартовое сочетание было занято: приложение откроет окно настроек на нужном разделе, а клавишу можно назначить заново в **Общих настройках / General settings** без перезапуска. Если не открывается плашка, проверьте разрешение микрофона Windows. Если текст не вставился, проверьте активное поле и буфер обмена; недоступность вставки в приложение с повышенными правами не считается успешной вставкой.
